## Modifications

The source data was transformed into seller-level analytical features and used for exploratory K-Means segmentation. The resulting CSV contains derived seller metrics and segment assignments; it is not the original source dataset.

The derived material is intended to be shared under CC BY-NC-SA 4.0, subject to the applicable license terms. Olist does not endorse this project.

## Limitations

The data describes historical activity. Segment assignments are exploratory, not causal, and sellers with few orders should be interpreted cautiously.
